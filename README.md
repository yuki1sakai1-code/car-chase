# 🏎️ Car Chase - 3D Touge Racing Game

本格的な頭文字Dスタイルの3D峠バトルレーシングWebゲームです。  
Three.jsを使用した完全3Dレンダリング、ダイナミックな車両物理演算、ドリフト機構、アニメ風キャラクター立ち絵演出、豊富な峠ステージ・ロケーションを搭載しています。

---

## 🎮 主な機能・特徴

- **15章に及ぶストーリーモード**:
  - 榛名山（秋名）、赤城山、妙義山、碓氷峠、正丸峠、日光いろは坂、箱根ターンパイク、首都高湾岸線など多彩なコースを収録。
  - 各エピソードに応じたライバル（藤原拓海、高橋涼介、高橋啓介、中里毅、真子＆沙雪、藤原文太など）との熱い1on1バトル。
- **実車感あふれる3Dマシンモデル**:
  - トヨタ AE86 スプリンタートレノ
  - 日産 スカイライン GT-R (R32)
  - マツダ アンフィニ RX-7 (FD3S)
  - ホンダ シビック TYPE R (EK9)
  - スバル インプレッサ WRX STI (GC8)
  - 本格JDMナンバープレート、3Dテールランプユニット、チタンマフラー、熱線デフロスター、ブレーキローター＆キャリパー等の緻密なリアビューディテール。
- **プロ仕様のアーケードHUD**:
  - 残り距離（REMAINING DISTANCE）
  - レーダーコンパスミニマップ（走行ライン・自車位置ナビ）
  - ステージセクター＆天候バッジ（朝/昼/夜/月夜/雪/雨）
  - 6速Hパターン シフトインジケーター（AT/MT対応）
  - アナログ＆デジタル統合タコメーター
- **マルチカメラ視点システム（全6視点）**:
  1. 三人称チェイス視点
  2. 三人称ワイド視点
  3. ボンネット視点
  4. コックピット（車内）視点
  5. バンパー（低空）視点
  6. 空撮ドローン視点
- **リッチな環境・風景グラフィック**:
  - 赤いトラス鉄橋、スノーシェッド（覆道）、雪の回廊、風力発電風車、温泉街（赤い大鳥居・旅館街）、パーキングエリア（PA）、長大トンネル、工場地帯（ガントリークレーン・サイロ）など、各峠の固有ランドマークをリアルタイム3D生成。

## 🕹️ 操作方法

| キー | アクション |
| :--- | :--- |
| **↑ / W** | アクセル（加速） |
| **↓ / S** | ブレーキ / バック |
| **← / A** | ステアリング（左） |
| **→ / D** | ステアリング（右） |
| **SPACE** | ハンドブレーキ（ドリフト開始） |
| **C** | カメラ視点切り替え（循環） |
| **1 〜 6** | 各カメラ視点へのダイレクト切り替え |
| **M** | サウンド ON / OFF |
| **T** | ランダム新コース即時生成 |
| **P** | オートパイロット ON / OFF |
| **L** | レースライン（走行軌道ガイド）表示切替 |
| **ESC** | コース選択画面へ戻る |

---

## 🚀 プレイ方法

特別なビルドや外部依存関係のインストールは不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. HTTPローカルサーバーで起動します（例: Pythonの場合）:
   ```bash
   python -m http.server 8000
   ```
3. ブラウザで `http://localhost:8000/index.html` にアクセスします。
